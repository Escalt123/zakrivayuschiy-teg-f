# Закрывающий тег

Учебная проектная работа по вёрстке: страница-рефлексия о пройденном пути обучения. Восемь карточек с фотографиями, личными заметками и анимированной кнопкой «Нравится», а также модальное окно «Сохранить на память».

**Демо:** https://github.com/Escalt123/zakrivayuschiy-teg-f
**Макет:** https://www.figma.com/design/Yg5IFeWSyl6Js98kWROjVP/4-%D1%81%D0%BF%D1%80%D0%B8%D0%BD%D1%82.-%D0%9F%D1%80%D0%BE%D0%B5%D0%BA%D1%82%D0%BD%D0%B0%D1%8F--%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%B0?node-id=0-1&p=f&clckid=5e412dd8

## Что реализовано

- **Макет по Figma с точностью до пикселя**, подход desktop-first. Одна контрольная точка: `@media (width <= 375px)`.
- **Резиновая вёрстка.** Ширина блоков задаётся одной переменной `--block-width` через `clamp()`. Тем же способом сделаны размеры шрифтов и отступы в шапке.
- **Фон из трёх градиентов.** Две сетки из `repeating-linear-gradient` и плавный переход цвета сверху вниз, фон закреплён (`background-attachment: fixed`).
- **Карточки.** Заголовок, фотография в обёртке с рамками, лейбл-водяной знак, два текстовых блока и кнопки действий. Лейбл сделан через `mix-blend-mode: hard-light`, обводка текста через `-webkit-text-stroke` с запасным вариантом на `text-shadow` внутри `@supports`.
- **Фильтры.** У каждой фотографии свой модификатор (`card__img--film`, `card__img--cat` и т. д.) с CSS-фильтрами, часть из них составные.
- **Кнопки.** Эффект наведения: чёрная плашка выезжает слева направо, цвет текста и иконки меняется через `mix-blend-mode: difference`. При фокусе появляется смещённая тень, у кнопки с сердцем — рамка.
- **Анимация сердца без библиотек.** Наведение, нажатие и клик описаны переходами `transition` и двумя `@keyframes`: масштабирование сердца и вспышка искр. SVG разобран на слои `contour`, `main-body`, `core` и `sparks`.
- **Модальное окно на `<dialog>`.** Открывается без JavaScript через атрибуты `command="show-modal"` и `commandfor`, закрывается кнопкой «ОК» (`<form method="dialog">`) или клавишей Esc. Фон стилизован через `::backdrop`.
- **Шрифты.** Вариативный Inter для основного текста и PressStart2P для акцентов. Подключены локально через `@font-face`.

## Технологии

HTML5, CSS3 (пользовательские свойства, `clamp()`, flexbox, grid, `@supports`, `mix-blend-mode`, фильтры, `transition`, `@keyframes`), БЭМ для именования классов. Единственный скрипт `scripts/like.js` входит в стартовый репозиторий и отвечает за переключение лайка.

## Структура проекта

```
.
├── .github/workflows/tests.yml   # автотесты
├── fonts/                        # шрифты и fonts.css
├── images/                       # фотографии карточек и фавиконки
├── scripts/like.js               # переключение лайка
├── styles/
│   ├── variables.css             # все CSS-переменные
│   ├── globals.css               # сброс стилей
│   ├── style.css                 # основные стили страницы
│   └── animations.css            # анимации сердца и @keyframes
├── svg/                          # symbol с дискетой и векторный фавикон
└── index.html
```

Классы, на которые опирается скрипт, менять нельзя: `like-icon`, `card__like-button`, `card__icon-button`, `is-liked`, `button__text`.

## Запуск

1. Склонируйте репозиторий.
2. Откройте проект через локальный сервер, например расширением **Live Server** для VS Code. Двойной клик по `index.html` не подойдёт: иконка дискеты подключается через внешний `<use href="./svg/diskette.svg#diskette">`, а такой запрос не работает при открытии файла напрямую.

## Поддержка браузеров

Рассчитано на актуальные версии Chrome, Firefox, Safari и Edge. Открытие диалога без JavaScript (`command` и `commandfor`) работает в Chrome 135+, Firefox 144+ и Safari 26.2+.
